# Unwindy — Landing Page

Página de promoción de la app Unwindy (calculadora de ciclos de sueño, sonidos relajantes, respiración guiada y alarmas inteligentes).

HTML/CSS/JS simple, sin frameworks ni build step — se publica directo con GitHub Pages.

## Estructura

- `index.html` — contenido de la página
- `styles.css` — estilos
- `script.js` — scroll suave y año dinámico del footer
- `assets/logo.png` — logo de la app
